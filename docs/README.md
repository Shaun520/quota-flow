## 新建文档规则

- 新文档按模块放入对应目录，不要继续使用 `docs/develop`。
- 文件名使用中文，保持简短且能看出主题。
- 如果文档属于已有模块，优先补充到对应目录，不额外创建平行目录。
- 涉及跨模块引用时，使用相对链接指向目标文档，并在改动后检查链接是否仍可访问。
