# 权限控制

> 状态：已实现，可通过 admin 端 `/desktop-permissions` 配置并实时同步到桌面端。

## Summary

在 admin 端新增“权限控制”配置，用来控制桌面端主 Tab 显示，以及主 Tab 下的核心功能入口显示开关。

- 控制粒度：全局默认 + 团队覆盖。
- 生效强度：UI 显示 + 前端路由兜底。
- 本轮不做主进程强校验，也不做按用户单独配置。
- 默认所有功能可见；没有团队覆盖时使用全局配置，有团队覆盖时按团队结果合并。

## 数据模型

新增迁移 `migrations/0022_desktop_permissions.sql`，表名为 `desktop_permissions`。

字段建议：

- `id`：UUID 主键。
- `target_type`：`global` 或 `team`。
- `target_id`：团队 id；`global` 时为空。
- `feature_key`：功能 key。
- `enabled`：是否显示。
- `updated_by`：最后修改管理员。
- `updated_at`：最后更新时间。

权限与实时性：

- authenticated 可读 `global` 行和自己所在团队的 `team` 行。
- admin 可全量管理。
- 加入 `supabase_realtime`，桌面端实时刷新权限配置。
- 默认不写 seed，缺失配置视为启用，避免影响现有用户。

## 功能清单

固定功能 key：

- 主 Tab：`tab.dispatch`、`tab.providers`、`tab.history`、`tab.team`、`tab.creation`。
- 调度台：`dispatch.text2video`、`dispatch.img2video`、`dispatch.multi_ref`、`dispatch.first_last`、`dispatch.first_frame`。
- 厂商：`providers.bind`。
- 历史：`history.detail`、`history.regenerate`、`history.copy_prompt`、`history.watermark_removal`。
- 创作中心（预留）：`creation.watermark`、`creation.storyboard`、`creation.community`。

`tab.creation` 本轮只作为预留配置项；桌面端当前没有创作中心代码，不会渲染该 Tab。后续实现创作中心时直接读取同一套权限。

## Admin 端

新增页面 `/desktop-permissions`，sidebar 放入“配置管理”，页面名称显示为“权限控制”。

- 支持编辑“全局默认”和指定团队的覆盖配置。
- 页面展示固定功能清单：主 Tab + 核心功能，每个功能是开关。
- 保存时写入该 scope 的完整配置：先删该 scope 已有行，再插入当前配置。
- 写审计日志。
- 保存时校验每个 scope 至少保留一个主 Tab，避免桌面端无导航可用。
- 团队选择复用现有 admin `listTeams`。

## 桌面端接入

新增 `useDesktopPermissions(userId, teamId)` hook：

- 拉取 global + 当前团队覆盖，合并出 `Record<feature_key, boolean>`。
- 缺失配置默认 `true`。
- 订阅实时变更，admin 保存后桌面端自动刷新。

接入点：

- `App.tsx` 用该 hook 过滤 `TABS`。
- 当前 `tab` 被禁用时，回退到第一个可见 Tab。
- `Dashboard.tsx` / `History.tsx` / `Providers.tsx` 接收权限开关，隐藏对应核心功能。
- 如果当前生成模式被禁，自动切回 `text2video`。

## 实施范围

- 不新增 IPC。
- 不改变主进程调度逻辑。
- 不改变历史任务数据结构。
- admin 和 desktop 各自维护一份静态 feature registry，key 命名以迁移内 `COMMENT` 和代码常量保持一致。

## 测试计划

静态验证：

- `pnpm --filter @quota-flow/admin typecheck`
- `pnpm --filter @quota-flow/admin build`
- `pnpm --filter @quota-flow/desktop typecheck`
- `pnpm --filter @quota-flow/desktop build`

手工验证：

- Admin 全局隐藏“历史”，桌面端顶部不再显示历史 Tab，`#tab=history` 自动回退到可见 Tab。
- 为某团队开启覆盖后，该团队桌面端生效；其他团队仍按全局配置。
- 关闭调度台图生/多参考/首尾帧后，调度台只保留文生视频模式，且当前隐藏模式被自动重置。
- 关闭历史“重新生成/复制提示词/去水印/详情”后，历史页和详情弹窗对应入口消失。
- 关闭厂商“账号绑定/管理”后，厂商页不再显示新增/绑定入口，已有账号查看不受影响。
- Admin 保存后桌面端实时生效，不重启桌面端也能看到变化。
- 现有豆包/千问/元宝/Dola 绑定与生成、历史、团队功能不回退。

## Assumptions

- 权限是“显示控制 + 前端路由兜底”，不在主进程做能力校验。
- 本轮不做按用户单独配置；先按当前用户所属团队应用团队覆盖。
- 功能开关不覆盖所有按钮级操作，只覆盖计划中列出的核心功能入口。
- 创作中心尚未实现，本轮仅预留配置项。
