# 桌面端“创作中心”主 Tab 模块规划

> 状态：设计文档。当前只记录方案，不改代码。

## 目标

在桌面端新增一个主 Tab“创作中心”，把围绕视频创作的高频能力集中到一个工作台里。第一版包含三块核心能力：

- 独立去水印工作台
- 分镜生成 UI 壳
- 社区优秀视频展示

同时预留轻量扩展：灵感模板、最近使用、收藏、一键回填调度台。

## 当前结论

- 模块定位：创作中心，而不是纯灵感库或并列入口。
- 分镜生成：第一版只做 UI 壳和示例结果，不接真实 AI 生成接口；真实 AI 后置。
- 社区优秀视频：第一版使用内置远程示例数据，不做 admin 管理。
- 去水印：复用现有本地 FFmpeg 引擎和 `window.api.watermark.*`，并把独立处理结果写入同一历史记录。
- 不改动豆包/千问/元宝/Dola 等已有厂商绑定和视频生成逻辑。

## 页面结构

建议在 `App.tsx` 增加 `creation` Tab：

- 主 Tab 名称：创作中心
- Hash：`#tab=creation`
- 保留现有 Tab：调度台、厂商、历史、团队

创作中心内部使用 segmented 切换：

- 去水印
- 分镜生成
- 社区优秀视频

页面顶部或侧边提供轻量入口区：

- 灵感模板
- 最近使用
- 收藏

## 去水印工作台

目标：用户选择本地视频后，可以在创作中心内预览、框选水印区域、处理、取消或重试，并把处理记录写入历史页。

数据流：

1. 用户选择本地视频文件。
2. 渲染层用现有 `JobService.insertJob` 创建历史 job：
   - `providerId = 'local'`
   - `mode = 'video_watermark'`
   - `status = 'running'`
   - `options.localPath = 本地视频绝对路径`
3. 调用现有 `window.api.watermark.process` / `retry` / `cancel` / `onProgress` 完成处理。
4. 处理结果写入 `options`：
   - `originalLocalPath`
   - `cleanLocalPath`
   - `watermarkBBoxes`
   - `watermarkStatus`
   - `watermarkMethod`
   - `watermarkError`
5. 历史页显示“本地工具 / 去水印”记录，原有历史页入口保留。

实现注意：

- 不新增数据库迁移，沿用 `jobs` 表。
- `useJobs.ts` 需要补充显示映射，让 `local` 显示为“本地工具”，`video_watermark` 显示为“去水印”。
- 框选交互可复用历史页现有思路：video 预览 + 绘制 bbox，再把显示坐标换算为视频原尺寸。

## 分镜生成 UI 壳

目标：先完成可用的创作入口，真实 AI 生成后置。

表单字段：

- 主题/题材
- 风格
- 角色/场景
- 镜头数

交互：

- 点击“生成分镜”后展示内置示例结果，不调用真实 AI。
- 按钮或文案明确提示当前是“UI 壳 / 待接入真实 AI”。
- 结果支持复制。
- 支持导出为文本/Markdown。
- 支持把分镜内容回填到调度台 prompt 或提示词区域。

## 社区优秀视频展示

目标：桌面端内置一批示例作品，帮助用户找灵感和复用提示词。

数据：

- 第一版使用静态远程示例数据，包含封面、MP4 URL、标题、标签、提示词。
- 不新增数据库表。
- 远程加载失败时显示兜底封面和错误态。

交互：

- 卡片展示封面、标题、标签、提示词摘要。
- 支持播放视频或展示封面。
- 支持收藏，收藏状态第一版可存 localStorage。
- 支持复制提示词。
- 支持“重新生成”，回填到调度台草稿。

## 扩展能力

第一版不把完整素材库或后台管理做进去，但页面结构预留：

- 灵感模板：常用风格、类型、Prompt 模板。
- 最近使用：本机最近生成/查看/收藏的作品。
- 收藏：社区优秀视频收藏和分镜收藏。

## 测试计划

静态验证：

- `pnpm --filter @quota-flow/desktop typecheck`
- `pnpm --filter @quota-flow/desktop build`

手工验证：

- 主 Tab 出现“创作中心”，hash 和切 Tab 状态正常。
- 去水印：选择本地视频、框选水印、处理、取消、重试均正常；历史页出现“本地工具/去水印”记录。
- 分镜生成：表单可填写，示例结果可复制/导出/回填调度台。
- 社区视频：示例卡片渲染正常，视频可播放或兜底封面，收藏/复制提示词/重新生成回填调度台正常。
- 回归：豆包/千问/元宝/Dola 绑定与生成、调度台、厂商、历史、团队均不回退。

## 后续迭代

- 分镜真实 AI 生成：接入 OpenAI 兼容接口或现有可用模型。
- 社区视频 admin 化：后台上传、分类、标签、审核发布。
- 收藏/最近使用落库：从 localStorage 升级为数据库记录。
- 素材库：统一管理本地图片、视频、参考素材。
- 创作工作流：分镜、素材、Prompt、生成、去水印串成一条链路。
