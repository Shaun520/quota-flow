# 阿里云百炼（Model Studio）接入方案

> 范围：首期 = **API Key 绑定 + 测试 Key + 账号级去重**（复用智谱/火山 apikey 厂商模式）。
> 额度 = **控制台会话捕获查真实免费额度**（同智谱/火山路线），作为后续迭代交付，本期预留会话捕获内核复用点。
> 内部 id：`bailian`；展示名：`阿里云百炼`。
> 方案校对时间：2026-08-20（已核对官方文档，接口字段以官网为准，接入前仍需实测）。

---

## 1. 摘要

把阿里云百炼作为第三个「API Key 型厂商」接入（模板见 `docs/厂商与API平台接入/智谱AI开放平台账号绑定.md` 与 `火山方舟API Key绑定.md`）：

- **数据面**：视频生成 API 为 Bearer Token 鉴权（`Authorization: Bearer sk-xxx` + `X-DashScope-Async: enable`），与智谱/火山同构，`test API Key` 复用「明文哈希 → 只读接口校验」。
- **额度面**：百炼真实免费额度在控制台 `costing-balance/free-quota` 页（**按业务空间维度**，分钟级更新、数据延迟约 1h），API Key 能否直读需实测；若不能，本期内**不实现额度查询**，按账号每日账本 `daily_total` 展示（同智谱 cogvideox-flash 现状）。**后续迭代**再捕获控制台会话查真实额度，复用智谱/火山的通用会话捕获内核。
- **去重**：百炼 `sk-` Key 归属**业务空间（WorkspaceId）**，免费额度按业务空间 + 阿里云账号维度（主账号与 RAM 子账号共享）划分 → 去重维度候选为 WorkspaceId。首期绑定时若能拿到 WorkspaceId 则按其指纹去重，拿不到回退 API Key 哈希（同智谱 customerId 逻辑）。
- 本轮交付：百炼在「绑定」弹窗可选、测试 Key、保存、账号级去重、账号明细展示（额度单位/默认日额度/等效除数隐藏），模型标签与视频生成延后。

## 3. 百炼接口实测/官方核对结论（2026-08-20）

### 3.1 鉴权方式
- 视频生成（数据面）：`Authorization: Bearer sk-xxx` + `X-DashScope-Async: enable`（**异步必须**，否则报 `current user api does not support synchronous calls`）。
- 免费额度（管控面）：控制台 `costing-balance/free-quota`，**API Key 能否直读需实测**；不可时需网页会话（与智谱 biz 同构）。

### 3.2 视频生成 endpoint（供后续迭代，本期规划）
- 北京：`POST https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis`
- 模型、endpoint、API Key 须**同地域**；`{WorkspaceId}` 为业务空间 ID（控制台「业务空间详情」），旧域名 `dashscope.aliyuncs.com` 仍可用。
- 轮询：`GET https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/tasks/{task_id}`（task_id 有效 24h，建议轮询 15s）。
- 视频结果 `video_url` 有效 24h，需及时转存（同智谱/火山，接历史持久化时必须处理）。
- 主推模型：`wan2.7-t2v`（文生）、`wan2.7-i2v`（图生，多模态：首帧/首尾帧/续写）；`wan3.0-video` 为邀测。另有 `happyhorse-1.0`（0.5 元/秒，按量）。
- **具体模型调用方法**（权威参考，需登录控制台查看）：`https://bailian.console.aliyun.com/cn-beijing?tab=api#/api/?type=model&url=3049634` —— 视频生成模型的 HTTP 调用 case（请求/响应/参数）；实现时以该页最新示例为准。

### 3.3 免费额度性质（关键差异，做方案或 UI 时需明确告知）
- 百炼视频免费额度是**首次开通一次性、90 天有效、按模型独立**（如视频 50 秒），**不是每日免费**，也不是持续活动期免费（区别于智谱/火山现状）。
- 模型各自独立免费额度；带日期快照版本与不带日期版本视为不同模型。
- 免费额度按**阿里云账号**维度统计，主账号与 RAM 子账号共享，且**中国内地所有业务空间共享**（已实测控制台文案）。
- **免费额度查看页（权威参考，需登录控制台，Vision 图像/视频页签）**：`https://bailian.console.aliyun.com/cn-beijing?tab=costing-balance#/costing-balance/free-quota?modelType=Vision` —— 后续会话捕获的目标页，据此实测「剩余量 / 总量 / 过期时间 / 用完即停」内部接口与字段。

### 3.4 防误扣（利好，后续迭代启用）
- 控制台「免费额度用完即停」开关：耗尽后返回 **HTTP 403 `AllocationQuota.FreeTierOnly`**，天然满足项目「免费额度耗尽绝不转付费」硬约束，**无需像火山那样做客户端拦截**，服务端开关即够。
- ⚠️ 前提：此能力依赖额度用尽时能拿到该 403 错误码（官方文档确认）。后续生成迭代接入时，把 403 归类为「额度耗尽」状态，提示开启用完即停。

## 4. 关键决策

1. **内部 id = `bailian`，展示名 = `阿里云百炼`**（沿用智谱 `zhipu`/火山 `volcengine` 短 id 风格；旧方案文档曾建议 `bailian_wan`，本仓库现有命名采用短 id，统一为 `bailian`）。
2. **首期范围**：绑定 + 测试 Key + 去重；不做额度、不做生成、不做模型目录。
3. **额度来源路线 = 控制台会话捕获查真实额度**（用户选定），本期不落地，作为 `docs/` 后续迭代替换本地账本展示；本期展示回退 `daily_total` 本地账本。
4. **去重维度**：优先 WorkspaceId（绑定流程若能随 key 校验顺带从密钥信息接口拿到），否则回退 API Key 哈希（同智谱 customerId 兜底逻辑）。
5. payload 复用 `{v:1,apiKey,consoleJwt}` 结构，与智谱/火山兼容，减少代码。
6. bailian 同 zhipu 在 apikey 场景隐藏额度单位/默认日额度/等效除数字段（智谱先例）。
7. **数据面测试 key 的只读校验路径需实测**：优先用开销为零的只读接口区分「无效 key(401)」。待定接口见 §5.3。

## 6. 后续迭代（额度 + 生成，本期仅规划）

### 6.1 真实额度（控制台会话捕获）——已实测（2026-08-20）
**关键更正**：免费额度按**账号维度**共享，非业务空间维度。控制台页明确「免费额度为中国内地下**所有业务空间共享**；其他地域无免费额度」。因此去重与额度记账的权威键为**阿里云账号 ID**（主账号 PK），而非 WorkspaceId。

**鉴权链路（实测）**：
- 首页域名 `bailian.console.aliyun.com` → 数据网关 `bailian-cs.console.aliyun.com`（跨子域，靠 `.console.aliyun.com` 身份 cookie 鉴权 + `sec_token` 反 CSRF）。
- 身份 cookie（实测）：`login_current_pk=1506525426020212`、`login_aliyunid_pk`、`cnaui`、`aui`、`yunpk`（都是账号 PK）→ 账号 ID 即**去重指纹键**。
- **`sec_token=` 为必填字段**（追加在 body 尾部，页面 SDK 计算注入）；缺失/格式错会导致跨域预检或鉴权失败。故外部无法用裸 Token 直接调，**必须复用控制台会话内核（页面内 hook 抓取/重放）**，与智谱/火山一致。

**接口（实测，两步异步）**：
- `POST https://bailian-cs.console.aliyun.com/data/api.json?action=BroadScopeAspnGateway&product=sfm_bailian&api=zeldaEasy.bailian-commerce.freeTrial.queryFreeTierQuotaAsyn&_v=`
- 类型：`application/x-www-form-urlencoded`，body=`params=<urlencoded JSON>&region=cn-beijing&sec_token=<token>`
- 第 1 步提交 `params.Data.queryFreeTierQuotaRequest = { modelType:"Vision", needOverviewInfo:true, needFreeTierOnlyStatus:true }` → 返回 `taskId`（异步）。
- 第 2 步轮询 `params.Data.queryFreeTierQuotaRequest = { taskId }` → 返回数据。
- `modelType` 枚举参考：`Vision`（视觉/视频）、`Audio`（语音）等；`params` 顶层 `{Api, V:"1.0", Data:{..., cornerstoneParam:{feTraceId:<uuid>, protocol:"V2", console:"ONE_CONSOLE", productCode:"p_efm", domain, consoleSite:"BAILIAN_ALIYUN", ...}}}`。

**响应结构（实测，供解析复用）**：
```
{ freeTierQuotas: [{
    model,                      // 如 wan2.7-t2v-2026-06-12
    quotaTotal,                 // 剩余额度（×quotaTotalPercentage%）
    quotaInitTotal,             // 初始免费额度
    quotaTotalPercentage,       // 剩余百分比（100=满）
    quotaValidityPeriod,        // 过期时间戳 ms
    quotaStatus,                // VALID / UNKNOWN（无免费额度，或带日期版才有）
    freeTierOnly                // 是否开启「用完即停」
  }...],
  freeTierQuotaOverview: { totalModelCount, modelsWithZeroQuota, ... },
  taskId }
```
- 前端会把结果缓存在 localStorage `CacheByUId-CURRENT_PK-<accountId>-free_quota_<ModelType>`（整表含全部模型）。
- **会话捕获内核实现建议**（最稳，复用智谱/火山 hook 内核）：加载登录态控制台免壳页 → hook 网络捕获 `queryFreeTierQuotaAsyn` 的成功响应（或从上述 localStorage 缓存读）→ 解析 `freeTierQuotas`。`sec_token` 由页面自身计算注入，内核无需自行构造；账号 PK 从 `login_current_pk` cookie 或 `free_quota_*` 缓存键中取。
- 会话过期 → 沿用 C 级自动续期内核。

**视频模型免费额度实测现状（供额度展示口径参考）**：
- `wan2.7-t2v-2026-06-12` 免费 50/50，过期 2026/09/30；
- `wan3.0-video` 免费 30/30；`wan2.7-r2v-2026-06-12` 免费 50/50；`happyhorse-1.1-t2v/r2v/i2v` 各 10；
- ⚠️ **`wan2.7-i2v`（图生视频）当前无免费额度**（`quotaStatus: UNKNOWN`）→ 图生视频走百炼即付费，接入生成时需提示/走防误扣；免费额度主要集中在文生/首尾帧（t2v/r2v）。

### 6.2 防误扣（沿用免费额度用完即停）
- 生成迭代接入 wen2.7 时：把 HTTP 403 `AllocationQuota.FreeTierOnly` 归类为「免费额度耗尽」→ 提示开启「免费额度用完即停」；不实现客户端硬拦截（服务端开关已兜底），与火山客户端拦截方案区分。

### 6.3 视频生成（api-branch）
- 新增 `ai/bailian` 生成分支（或复用现有 ApiGenerationBranch，参照 `volcengine` 接入方式）：提交 `POST .../video-serving/video-synthesis`（`X-DashScope-Async: enable`）→ 轮询 `GET .../api/v1/tasks/{task_id}` → 取 `video_url` + `usage.duration`。
- 图生视频模型 `wan2.7-i2v` 的图片 role（first_frame/last_frame）与项目现有 wan/seedance 处理方式对齐（见 memory：Seedance 图片 role 区分）。
- 视频 URL 24h 有效需转存 Supabase（复用 `jobOptions.images`/资源持久化链路）。
- provider_caps + spec MODEL 模型目录上线后 Admin 可配。
