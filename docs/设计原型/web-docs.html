快速开始

Quota-Flow 是一款桌面端工具，所有功能都在桌面端完成。落地页只做介绍，不承载产品功能。

1. 下载安装

访问 下载页，根据系统自动获取对应安装包。目前支持 Windows、macOS 与 Linux。

# Windows
Quota-Flow Setup x.y.z.exe

# macOS
open Quota-Flow-x.y.z.dmg

# Linux (AppImage)
chmod +x Quota-Flow-x.y.z.AppImage
./Quota-Flow-x.y.z.AppImage

2. 选择使用模式

首次启动会提示选择模式：

  • 官方托管（推荐）：注册账号即可使用，团队无席位上限，适合绝大多数用户。
  • 自部署：数据完全由自己掌控，无席位限制，适合技术用户或隐私敏感场景。

自部署用户需要自备 Supabase 项目，并手动执行 migrations。详见下方「自部署教程」。

3. 绑定厂商账号

进入桌面端「设置」Tab，点击「绑定厂商」，按引导登录各家平台。登录完成后，cookie 会自动加密存储，额度会同步到账本。

  • 个人账号：本地内存解密，不上传云端。
  • 团队公共账号：加密上传 Supabase，成员通过 Edge Function 代调用，明文不出云端。

4. 生成第一个视频

切换到「调度台」Tab，输入 prompt 并选择时长/分辨率，点击「生成」。系统会自动：

  1. 估算本次消耗
  2. 选择可用额度最多的厂商账号
  3. 后台提交生成请求
  4. 返回视频 URL 并写入历史

首次生成建议在 prompt 中指定「5 秒、720p」，这是大多数厂商免费额度支持的基础配置。

自部署教程

自部署适合希望完全掌控数据的技术用户。你需要自己注册 Supabase 并维护 migrations。

前置要求

  • Node.js ≥ 20
  • pnpm 9.7.0+
  • 一个空的 Supabase 项目（已启用 Auth + Postgres）
  • Git

安装步骤

  1. 克隆仓库并安装依赖 
    git clone https://github.com/Shaun520/quota-flow.git
cd quota-flow
pnpm install
pnpm build
  2. 配置环境变量 
    cp .env.example .env
# 编辑 .env，填入：
# SUPABASE_URL=https://your-project.supabase.co
# SUPABASE_ANON_KEY=your-anon-key
# SELF_HOSTED=true
  3. 执行数据库迁移

    按序执行 migrations/*.sql 中的脚本。方式 A：在 Supabase Dashboard 的 SQL Editor 中逐个执行；方式 B：等待桌面端首次启动时提示自动执行。

  4. 启动桌面端 
    cd apps/desktop
pnpm dev

    首次启动时，在设置中填入 Supabase URL 与 anon key，然后注册或登录即可。

CLI 真跑示例

自部署用户也可通过 CLI 验证调度与额度：

# 查看额度总览
pnpm --filter @quota-flow/cli dev check-quota

# 指定厂商生成
pnpm --filter @quota-flow/cli dev generate --mode text2video \
  --prompt "生成5秒猫咪视频" --provider yuanbao --json

# 不指定厂商，走智能调度
pnpm --filter @quota-flow/cli dev generate --mode text2video \
  --prompt "生成5秒猫咪视频" --json

# 刷新账本
pnpm --filter @quota-flow/cli dev refresh

自部署用户不享受官方客服支持。遇到问题可在 GitHub Issues 提出，但不承诺 SLA。

厂商清单

Quota-Flow 目前接入 7 家 AI 视频生成厂商。除 mathmind 走真 API 外，其余 6 家均通过 WebView 统一执行引擎调用。

厂商 产品 额度单位 影响因素 调用方式
豆包 doubao.com 次数 时长（5s/10s） WebView cookie 注入
即梦 jimeng.jianying.com 灵感值 时长 + 分辨率 + 模型 WebView cookie 注入
通义万相 tongyi.aliyun.com 次数 时长 WebView cookie 注入
元宝混元 yuanbao.tencent.com 次数 固定次数 WebView cookie 注入
可灵 klingai.kuaishou.com 积分 时长 + 分辨率 WebView cookie 注入
海螺 hailuo.com 次数 固定次数 WebView cookie 注入
MathMind mcp_mathmind-video 次数 固定次数 真 API

关于扣减单位

不同厂商的免费额度单位不同：豆包/元宝/海螺按「次数」，即梦按「灵感值」，可灵按「积分」。系统通过 provider_cost_tables 维护各家消耗规则，最终折算成统一的「等效次数」用于总览展示。

例如：即梦 5 秒 720p 文生视频可能消耗 80 灵感值，若该厂商的等效分母为 80，则在团队总池中计为 1 次等效次数。

接入新厂商

得益于 WebView 统一执行引擎，新增一家 cookie 厂商通常只需填写一份 WebProviderConfig：

  • 登录页 URL 与生成页 URL
  • prompt 输入框与发送按钮选择器
  • 结果提取方式（拦截响应 / 读取 DOM / 执行页面 JS）
  • cookie 健康检查接口

无需逆向各家风控签名，平均 2 小时即可完成接入。

常见问题

不是传统 SaaS。Quota-Flow 是开源桌面端工具，官方提供托管的数据库与团队协作功能。你也可以完全自部署，脱离官方托管。

个人自绑的 cookie 只在本地内存解密，不会上传。团队公共 cookie 会加密后存到 Supabase，成员通过 Edge Function 代调用，明文不出云端。

国内主流厂商的免费额度绑登录态，公开 API 是付费按量的。WebView 方案直接复用厂商官方页面，自带风控签名，无需逆向，接入新厂商只需填选择器。

团队总池 = admin 绑定的公共额度 + 成员自愿贡献的自带额度。不同厂商的原生单位按消耗表折算成「等效次数」用于总览 UI，实际扣减仍按各厂商原生单位执行。

不同厂商寿命不同，一般为 7-30 天。系统每天凌晨 3 点后台静默访问厂商首页自动续命，目标是将重新登录频率降到平均 1-2 个月一次。

个人免费版包含全部核心功能与 7 家厂商接入，唯一区别是不能创建团队共享池，仅限 1 人使用。
