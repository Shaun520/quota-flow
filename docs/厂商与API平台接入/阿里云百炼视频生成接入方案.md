# 阿里云百炼（bailian）视频生成接入方案

> 生成目的：在现有「API Key 型厂商」视频生成链路中，把阿里云百炼（`bailian`）作为新生成分支接入，覆盖文生（t2v）、参考生（r2v）、图生（i2v，含首帧/首尾帧/视频续写）等模式，并沿用项目现有的分辨率/画幅比例选项与「把视频参数追加进提示词」的既有做法。
> 规划时间：2026-08-20。

## 1. 摘要

- 在 `apps/desktop/src/main/api-branch.ts` 新增 `makeBailianBranch()`，注册进 `API_BRANCHES.bailian`，复用既有 `ApiGenerationBranch` 统一接口（同 zhipu/volcengine）。
- 在 `packages/providers/src/bailian.ts`（或同目录新增 `bailian-video.ts`）实现百炼视频生成的数据面提交 + 异步轮询函数。
- 生成参数：分辨率（720P/1080P，映射调度台 720/1080）、画幅比例（16:9/9:16/1:1/4:3/3:4）、时长（2–15s，按模型档位）、配音 on/off；并把 `时长/尺寸/画幅/配音` 追加进 `prompt`（用户明确要求，对齐智谱 `generate` 的做法）。
- 防误扣：依赖百炼服务端「免费额度用完即停」返回 403 `AllocationQuota.FreeTierOnly` → 归类为额度耗尽提示，不做客户端暴力拦截；图生 `wan2.7-i2v` 无免费额度，属付费按量，生成前用账号免费额度快照提示/放行。
- 视频 URL 24h 有效 → 结果经 `ApiGenerateOutcome.videoUrl/coverImageUrl` 返回，由现有转存链路落 Supabase（复用 `jobOptions.images` 持久化，不改）。

### 1.1 首版范围（用户确认：完整全家桶）
| 统一 mode | 模型 | 说明 | 免费额度（实测见文档 §6.1） |
|---|---|---|---|
| `text2video` 文生 | `wan2.7-t2v-2026-06-12` | 音频同步、多镜头，720P/1080P，2–15s，30fps | 有（实测 50） |

## 3. 官方调研结论（2026-08-20，来源为阿里云百炼官方文档 + 实测，使用前仍需在控制台权威 API case 页核对字段名）

来源：
- 官方模型能力/价格/时长/分辨率：`help.aliyun.com/zh/model-studio/*`（wan2.7-t2v / wan2.7-i2v / wan2.7-r2v / 视频生成与编辑总览）。
- 请求/响应协议字段：DashScope 视频生成通用协议（异步提交 + 轮询 `tasks/{task_id}`）；**具体 input/parameters 字段名须以控制台「API 调用 case 页」为准实测**——官方权威入口：`https://bailian.console.aliyun.com/cn-beijing?tab=api#/api/?type=model&url=3049634`（视频生成 HTTP 调用示例，需登录，故实现时实测核对）。

### 3.1 模型 × 参数（官方）
| 模型 | 类型 | 分辨率 | 演示时长 | fps | 价格（北京，元/秒） |
|---|---|---|---|---|---|
| `wan2.7-t2v-2026-06-12` | 文生（Audio+Text→Video） | 720P/1080P | 2–15s | 30 | 720P 0.6 / 1080P 1 |
| `wan2.7-i2v-2026-04-25` | 首帧/首尾帧/续写 | 720P/1080P | 2–15s | 30 | 同上（图生无免费，按量） |
| `wan2.7-r2v-2026-06-12` | 参考图/参考视频 | 720P/1080P | 2–10s | 30 | 同上 |

- 免费额度（实测，见接入方案 §6.1）：`wan2.7-t2v-2026-06-12` 50、`wan2.7-r2v-2026-06-12` 50；`wan2.7-i2v-2026-04-25` **无免费**（`quotaStatus: UNKNOWN`）。

### 3.2 协议骨架（DashScope 异步视频生成，字段以实测为准）
- 提交：`POST {BASE}/api/v1/services/aigc/video-generation/video-synthesis`，Header `Authorization: Bearer <sk-...>` + `X-DashScope-Async: enable`。
- body（示意，字段名待实测）：
```
{ "model": "wan2.7-t2v-2026-06-12",
  "input": { "prompt": "...", /* i2v: img_url(首帧) / img1_url+img2_url(首尾); r2v: 参考图 */ },
  "parameters": { "resolution": "720P"|"1080P", "ratio": "16:9"|"9:16"|"1:1"|"4:3"|"3:4",
                  "duration": 5, "prompt_extend": true, "watermark": false } }
```
- 提交响应：`request_id` + `output.task_id`（异步）。
- 轮询：`GET {BASE}/api/v1/tasks/{task_id}` → `output.task_status`（PENDING/RUNNING/SUCCEEDED/FAILED…）、成功后 `output.results[].url`（视频，24h 有效）、`output.results[].cover_url`（封面）。
- 失败/额度耗尽：HTTP 403 `AllocationQuota.FreeTierOnly`（免费额度用完即停，服务端兜底）。
- endpoint 域名：优先用现有 `dashscope.aliyuncs.com` 通用域名（无需 WorkspaceId，`BAILIAN_TASK_BASE_URL` 已存在）；若该端返回 404/需空间，回退 §3.2 规划确认的「业务空间前缀域名」（`https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/...`）。**实现时实测二选一，不臆造。**

## 4. 变更清单

### 4.1 `packages/providers/src/bailian.ts`（新增视频生成数据面）
- 新增常量 VIDEO_SYNTHESIS_* 、模型/参数静态表、`bailianGenerateWithKey(...)`、`pollBailianTask(...)`：
  - 常量：提交端点（§3.2）、轮询端点（复用 `BAILIAN_TASK_BASE_URL`）。
  - 静态表 `BAILIAN_VIDEO_MODELS`：model → { type(t2v|i2v|r2v), availableResolutions, maxDuration(10/15), pricePerSec(0.6/1), supportedModes }。
  - `bailianGenerateWithKey(apiKey, opts)`：opts 含 `model/mode/prompt/negativePrompt?/images(https 数组)/durationSec/resolution/ratio/audio/promptAudioUrl?`；构造 §3.2 body（按 mode 决定图片字段），提交 → 轮询（PENDING/RUNNING 循环，超时上限，参考智谱/火山轮询节奏）→ 返回 `{ ok, videoUrl, coverImageUrl, traceId(task_id), error }`。
  - 403 归为 `error` 携带额度耗尽标识（`{ freedTierExhausted: true }` 或归一化 message），供 dispatch/UI 提示。
  - **保持无痕轮询、不刷接口**（遵守 AGENTS 高频轮询约束：放宽轮询间隔）。
- `cost`/免费判定：视频模型成本建议——t2v/r2v 免费明细来自 payload `freeTiers`；i2v 无免费 → 成本按付费（见 §4.2 cost）。金额在账本记录（costAmount 展示）参考百炼现有「不计原子扣减」约束。

### 4.2 `apps/desktop/src/main/api-branch.ts`（新增百炼分支）
- 新增 `makeBailianBranch(): ApiGenerationBranch` 并注册 `API_BRANCHES.bailian`（对齐 zhipu/volcengine）：
  - `parseCredentials`：`decodeBailianPayload(decrypted)` → `{ apiKey }`（生成用 API Key，`consoleJwt/cookies` 不需要）。
  - `cost(model)`：t2v/r2v = 0（免费，但需防 403）；i2v = 1（付费按次，仅作展示，真钱按量）；按模型返回。
  - `supportedDurations(model)`：t2v/i2v → `[5, 10]`；r2v → `[5]`（官方 2–10/2–15，UI 档位取 `[5,10]`，r2v `[5]`）。**是否加入其它档位由调度台 resolution 与免费额度过寿，实现时定死并在 UI 一致。**
  - `modes`（`ApiModelInfo.modes`）：t2v=`[文生视频]`；i2v=`[图生视频(首帧), 首尾帧]`；r2v=`[参考生视频]`。
  - `catalog()`：优先用账号 `freeTiers`（payload）过滤出未过期视频模型（复用 `isBailianVideoFreeModel` + 不 expired），补足免费额度；i2v 无免费额度走付费，展示「付费/按量」标签；回退内置静态目录（§4.1 静态表）。
  - `preflight?(model, plain)`：i2v 无免费额度 → 生成前返回 `{ ok: false, reason: '该模型按量付费，将扣账号余额，是否继续？' }` 或放行标记；实现时确认 dispatch 是否对 preflight 拦截有 UI 确认入口，若无则改为提示。
  - `generate(input, creds, params)`：
    - 过滤 `params.images` 只留 `https?://`（图生/首尾/参考均需公网 URL，调度台上传 Supabase 已有）。
    - 按 `mode` 定价用到图片数：img2video=1（首帧）、first_last=2（首帧+尾帧）、multi_ref=1（参考）、text2video=0；不足则返回错误（对齐智谱 L249-L255）。
    - 构造百炼 `input`/`parameters`（§3.2），`resolution('720'→'720P', '1080'→'1080P')`、`ratio=input.ratio`、`duration=params.durationSec`、`audio`（on/off 落在音频开关，默认有声）。
    - **视频参数追加进 prompt**：`"${prompt}（视频参数：画面尺寸 ${size}、画幅 ${ratio}、时长 ${duration} 秒、${配音?}）"`，对齐智谱 L286-L290。
    - 调 `bailianGenerateWithKey`，映射返回 `{ ok, videoUrl, coverImageUrl, traceId, error }`，透传 403 额度耗尽信息。
- `provider:api-models` bailian 已实现，不改；但「查看模型」明细与 catalog 口径保持「已捕获未过期视频模型」。

## 5. 决策与假设

1. **范围 = 完整全家桶**（用户选定）：t2v（免费）+ r2v（免费）+ i2v（图生/首尾帧，付费按量）。续写延后（无统一 mode）。
2. **沿用调度台分辨率（720/1080P）与画幅比例下拉**（用户选定），映射为百炼 `parameters.resolution/ratio`。
3. **视频参数追加进 prompt**（用户明确要求），对齐智谱 generate 的既有实现。
4. **endpoint 用 `dashscope.aliyuncs.com` 通用域名**，避开 WorkspaceId；如不可用再回退业务空间域名（实测定）。
5. **防误扣依赖服务端 403**（t2v/r2v），不做客户端暴力拦截；**i2v 按付费处理**，生成前用账号免费额度快照提示/放行。
6. **额度记账**：继续遵守「百炼不做原子扣减、仅记 costAmount 用于展示」的既有约束；付费模型金额仅为展示标签。
7. **字段名以控制台权威 API case 页实测为准**：input/parameters 的图片字段（img_url/img1_url+img2_url）与 watermark 支持，不臆造。

## 6. 防误扣与付费路径

- t2v/r2v（免费额度充足区）：提交前可用 payload `freeTiers` 快照读该模型剩余，为 0 → 提示；但**不硬拦**（百炼服务端 403 已兜底，与文档 §6.2/§3.4 一致）。
- **403 `AllocationQuota.FreeTierOnly`** → 归一化为「该模型免费额度已用完，请开启『免费额度用完即停』再试」提示，落 job 状态。
- i2v（无免费）：`preflight` 返回付费确认理由；`catalog` 标 `priceLabel='按量付费'`，避免用户误以为免费。
- 高频轮询约束：轮询采用固定间隔（如 ≥10s）且带超时上限，不做 DB 写入高频轮询。
