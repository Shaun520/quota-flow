核心特性

从额度归集到智能调度，从多账号池化到团队共享，让每一份免费额度都物尽其用。

动态额度账本

按次数、灵感值、积分等原生单位实时记账；按时长、分辨率、模型动态扣减，每日自动刷新。

智能调度 + 预检查

提交前预估算本次消耗，自动跳过余额不足账号，为每一次创作挑选最划算的厂商。

多账号池化

同一厂商绑定多个账号，额度自动叠加；单账号失效时无缝 failover，创作不中断。

团队共享池

多人多账号额度汇入团队池，统一配额与审计。小团队也能把免费创作力放大数倍。

Cookie 自动续命

隔离会话 + 实例池共享，凌晨静默续期。平均 1–2 个月才需重新登录一次，省心省力。

快速接入新厂商

声明式配置页面地址与 DOM 选择器，无需逆向 bx-ua 等风控签名，新厂商约 2 小时即可上线。

三步开始调度

桌面端是创作入口，WebView 引擎在后台完成厂商调用，Supabase 负责账本与团队协作。

1

绑定账号

在桌面端授权登录各厂商，额度自动归集到统一账本，Cookie 本地安全保存。

2

一键生成

输入创意与参数，系统自动预估消耗、选择厂商、提交任务；失败时无缝切换次优方案。

3

额度共享

个人账号本地解密自用，团队账号由 Edge Function 代调用，密钥始终留在云端之外。

桌面端 Electron

React 交互界面 + 本地调度引擎，创作唯一入口

WebView 统一引擎

Cookie 注入、自动提交、实例池共享与续期
